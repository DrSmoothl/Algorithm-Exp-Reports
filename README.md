# 数据结构与算法实验报告

这是一个基于GitHub Pages部署的数据结构与算法实验报告集合，使用DaisyUI构建了现代化的响应式界面。

## 🌟 特性

- 📱 **响应式设计**：完美适配不同设备和屏幕尺寸
- 🎨 **现代UI**：基于DaisyUI的精美界面设计  
- 🚀 **性能优化**：快速加载，流畅交互
- 📚 **详细文档**：包含完整的问题分析、算法设计和代码实现
- 🔍 **易于导航**：清晰的目录结构和导航系统

## 📖 实验列表

### 实验一：鱼与熊掌兼得问题
- **算法核心**：位运算 + 哈希表优化
- **主要技术**：bitset、集合交集统计
- **复杂度**：O(Q + unique × n) 时间，O(n × m/8 + Q) 空间
- [查看详细报告](https://drsmoothl.github.io/Algorithm-Exp-Reports/experiment1.html)

## 🛠️ 技术栈

- **前端框架**：原生HTML + CSS + JavaScript
- **UI组件库**：DaisyUI + Tailwind CSS
- **代码高亮**：Prism.js
- **部署平台**：GitHub Pages
- **编程语言**：C++

## 🎯 设计理念

1. **用户体验优先**：注重界面的直观性和易用性
2. **内容为王**：详细的算法分析和清晰的代码解释
3. **性能优化**：快速加载和流畅的交互体验
4. **移动友好**：完美适配各种设备
